# 생기부 도우미

초등학교 교사가 수행평가 결과를 바탕으로 교과별 학기말 종합의견을 작성하고 편집하는 업무 도구의 1단계 화면입니다.

## 현재 구현 범위

- 파스텔 블루 상단 메뉴와 평가관리 사이드바
- 학년도, 학기, 학년, 반, 교과 조회 조건
- 접이식 평가 계획, 예시문, 추가 지시사항, 비밀번호 입력 영역
- 학생별 평가결과 및 학기말 종합의견 표
- 더미 종합의견 전체 생성 및 선택 생성
- 결과 직접 수정, 복사, CSV 다운로드
- 행 추가, 선택 삭제, 전체 초기화
- 더미 월 사용량 상태 표시

현재 단계에서는 OpenAI API, 서버 라우트, 실제 비밀번호 인증, 데이터베이스, 실제 사용량 계산을 연결하지 않습니다. 비밀번호는 브라우저에서 입력 여부만 확인하며 학생 정보와 생성 결과를 서버나 데이터베이스에 저장하지 않습니다. 새로고침하면 초기 더미 데이터로 돌아갑니다.

## 실행 방법

Node.js 20.19 이상과 pnpm이 필요합니다. 테스트 도구인 Vite 8의 Node.js 요구사항에 맞춘 버전입니다.

```bash
pnpm install
pnpm dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 검증 방법

```bash
pnpm typecheck
pnpm test:run
pnpm build
```

## 다음 단계

다음 단계에서는 브라우저에서 OpenAI를 직접 호출하지 않고 `app/api/generate-report/route.ts` 서버 라우트를 추가합니다. 서버에서 비밀번호 확인, 요청 제한, 월 예산 확인, OpenAI 호출과 사용량 저장을 처리하며 학생 이름과 평가 원문 및 생성 결과는 데이터베이스에 저장하지 않습니다.
