# 과목별 자료 작업공간과 균형 평어 생성 설계

## 목표

교사가 과목별 평가 계획, 수행평가지, 영역별 평가결과 PDF를 한 화면에서 등록하면 문서에서 영역명, 학생 번호, 성취 단계를 자동 추출하고 지정한 영역 수만큼 학생별 근거를 선택하여 학기말 종합의견을 생성한다. 학생 성명은 원문에서 읽더라도 화면과 외부 요청에서는 `1번 학생` 형식으로 익명 처리한다.

## 화면 구조

기존 학년도, 학기, 학년, 반 조회 조건은 제거한다. 초기 학생 표도 표시하지 않는다.

상단에는 다음 과목을 선택하는 작업공간을 둔다.

- 국어
- 수학
- 사회
- 과학
- 영어
- 음악
- 미술
- 체육
- 실과
- 도덕

선택한 과목 안에서 다음 자료를 등록한다.

- 평가 계획: HWP, HWPX, PDF 한 개
- 수행평가지: HWP, HWPX, PDF 여러 개
- 영역별 평가결과: PDF 여러 개
- 평어에 반영할 영역 수

모든 파일 입력은 파일 선택과 드래그 앤 드롭을 지원한다. 영역명 입력란은 없애고 각 평가결과 PDF의 표에서 영역명을 자동 추출한다. 평가결과 PDF 개수는 고정하지 않으며, 교사가 선택한 반영 영역 수는 분석된 영역 수를 넘을 수 없다.

자료는 React 메모리에만 유지한다. 새로고침하거나 탭을 닫으면 원본 파일, 분석 결과, 생성 평어가 모두 사라지고 다시 업로드해야 한다. 브라우저 저장소와 데이터베이스에는 저장하지 않는다.

## 분석 결과와 학생 표

자료 분석이 끝나기 전에는 학생 표를 만들지 않는다. 분석 후에는 영역별 PDF에서 찾은 학생 번호의 합집합을 기준으로 필요한 행만 자동 생성한다.

표는 다음 열을 표시한다.

- 번호
- 익명 성명
- 과목
- 선택된 영역
- 영역별 성취 단계
- 학기말 종합의견

익명 성명은 학생 번호를 이용해 `1번 학생`, `2번 학생`처럼 표시한다. 원래 성명은 서버 로그, 분석 응답, 데이터베이스, OpenAI 요청에 포함하지 않는다.

화면에는 다음 안내를 명확히 표시한다.

> 개인정보 보호를 위해 평가결과 파일의 학생 성명은 저장하거나 외부 서비스로 전송하지 않습니다. 학생 번호는 유지하고 성명은 자동으로 익명 처리합니다. 교사는 원본 평가결과 파일의 번호와 대조하여 결과를 확인할 수 있습니다.

## 영역명과 성취 단계 추출

각 평가결과 PDF에서 영역명과 학생별 단계를 읽는다. 단계는 다음 네 값으로 정규화한다.

1. 매우 잘함
2. 잘함
3. 보통
4. 노력 요함

영역명이나 단계를 확정할 수 없는 파일은 자동 추측해 생성하지 않고 해당 파일과 학생 번호를 검토 대상으로 표시한다. 모든 생성 대상 학생의 필요한 단계가 확인되어야 평어 생성을 허용한다.

## 학생별 영역 선택 알고리즘

교사가 업로드한 평가결과 영역 수와 평어에 반영할 영역 수는 서로 독립적이다. 예를 들어 국어 평가결과 PDF가 4개이고 반영 영역 수가 3개이면 각 학생에게 4개 중 3개를 선택한다.

선택은 두 단계로 수행한다.

### 1단계 성취 수준 우선

각 학생의 영역을 다음 순서로 정렬한다.

1. 매우 잘함
2. 잘함
3. 보통
4. 노력 요함

필요한 개수만큼 상위 수준부터 채운다. 균형을 맞추기 위해 더 높은 수준의 영역을 제외하고 낮은 수준을 선택하지 않는다.

### 2단계 반 전체 균형

같은 성취 수준의 후보가 필요한 수보다 많을 때는 해당 시점까지 반 전체에서 선택된 횟수가 적은 영역을 우선한다. 선택 횟수도 같으면 학생 번호와 영역 순서를 이용한 안정적인 순환 규칙으로 결정한다.

따라서 동점 후보가 충분하면 학생별 조합이 `1·4영역`, `2·3영역`, `1·3영역`처럼 분산된다. 모든 학생에게 `1·2영역`만 반복되는 현상을 방지한다. 알고리즘은 같은 입력에서 항상 같은 결과를 내도록 결정적으로 구현한다.

## 평어 생성

OpenAI에는 다음 최소 정보만 보낸다.

- 익명 학생 번호
- 과목
- 선택된 영역명과 단계
- 이름과 식별정보를 제거한 평가 계획 및 수행평가지 내용
- 예시문과 추가 지시사항

평어는 선택된 영역만 근거로 작성한다. 매우 잘함은 강점이 구체적으로 드러나게 쓰고, 잘함, 보통, 노력 요함도 긍정적 성장 표현으로 작성한다. 기존 금지어, 외국어, 제품명, 특수문자 검사와 문장 유사도 점검을 유지한다.

## 오류 처리

- 평가결과 PDF가 없으면 분석 불가 안내
- 영역 자동 추출 실패 시 파일별 재등록 또는 확인 안내
- 분석된 영역 수보다 큰 반영 영역 수 선택 차단
- 학생 번호가 영역 파일마다 불일치하면 누락 번호 표시
- 같은 번호의 단계가 한 파일에서 중복되면 생성 차단
- OpenAI 요청 전 익명화 결과를 서버에서 한 번 더 검증

## 테스트

- 이름이 있는 PDF에서도 분석 응답과 생성 요청에 이름이 없는지 확인
- 새로고침 전에는 상태가 유지되고 컴포넌트 재마운트 후 초기화되는지 확인
- 영역명 자동 추출과 여러 PDF 병합 확인
- 매우 잘함 우선 선택 확인
- 동점 영역이 학생 전체에 균형 있게 분포하는지 확인
- 균형 때문에 더 낮은 단계를 선택하지 않는지 확인
- 분석 전 학생 표가 없고 분석 후 정확한 행 수가 생성되는지 확인
- 드래그 앤 드롭과 파일 선택이 동일하게 동작하는지 확인
