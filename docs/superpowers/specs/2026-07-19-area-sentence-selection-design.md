# 교과 평어 영역 선택 및 문장 수 보장 설계

## 목적

교사가 등록한 평가 영역 중 `평어 반영 영역 수`에 지정한 개수만 학생별로 선택하고, 선택된 각 영역마다 정확히 한 문장의 학기말 종합의견을 생성한다. 영역 선택은 성취 단계 우선순위를 절대적으로 지키면서 같은 단계 안에서만 반 전체 영역 분포를 균형 있게 조정한다.

## 확정된 동작

예를 들어 평가 영역이 네 개이고 반영 영역 수가 세 개라면 모든 학생에게 정확히 세 영역을 선택한다. 학생의 단계가 `매우 잘함` 두 개, `잘함` 한 개, `노력 요함` 한 개라면 앞의 세 영역을 선택한다.

선택 순서는 다음과 같다.

1. 매우 잘함
2. 잘함
3. 보통
4. 노력 요함

반 전체 균형은 같은 성취 단계인 후보 사이에서만 적용한다. 사용 횟수가 적은 영역을 우선하고, 그래도 같으면 학생 번호를 기준으로 영역 시작 위치를 순환한다. 어떤 경우에도 영역 균형을 위해 더 낮은 성취 단계의 영역을 선택하지 않는다.

## 생성 응답 구조

현재처럼 학생별 평어 전체를 하나의 `comment` 문자열로만 받지 않는다. 모델은 학생별로 다음 정보를 구조화해 반환한다.

- 학생 번호
- 선택 영역과 성취 단계
- 영역별 평어 배열
  - 영역명
  - 해당 영역에 관한 한 문장

서버는 다음 조건을 검증한다.

- 응답 학생 번호가 요청 학생 번호와 일치하는가
- 영역별 평어 배열의 길이가 학생에게 선택된 영역 수와 일치하는가
- 응답 영역명이 선택 영역과 빠짐없이 일치하는가
- 영역마다 비어 있지 않은 한 문장이 존재하는가

검증을 통과하면 영역별 문장을 선택 영역 순서대로 공백으로 이어 기존 프론트엔드의 `comment` 필드로 반환한다. 따라서 기존 표 수정, 복사, CSV 다운로드 기능은 그대로 유지한다. 검증이 실패한 결과를 조용히 표시하지 않고 안전한 오류를 반환한다.

## 평어 작성 규칙

- 선택 영역 하나당 정확히 한 문장을 작성한다.
- 세 영역을 선택하면 총 세 문장을 작성한다.
- 각 문장은 해당 영역의 평가 계획, 수행평가지와 성취 단계만 반영한다.
- 기본적으로 명사형 종결어미를 사용한다.
- 기존의 긍정적 표현, 금지어, 외국어, 제품명, 특수문자 제한을 유지한다.
- 여러 영역의 내용을 한 문장에 합치거나 한 영역을 여러 문장으로 늘리지 않는다.

## 화면 조정

- 영역별 성취 단계 열은 `매우 잘함`이 잘리지 않을 정도로 넓힌다.
- 드롭다운 내부 글자와 화살표가 겹치지 않도록 최소 너비와 좌우 여백을 확보한다.
- 학기말 종합의견 열은 영역 열 증가분만큼 줄인다.
- 종합의견은 가로로 넘치지 않고 셀 안에서 자연스럽게 줄바꿈한다.
- 일반적인 데스크톱 너비와 네 개 영역 기준에서 가로 스크롤 없이 핵심 열이 보이게 한다.

## 오류 처리

- 학생에게 등록된 평가 영역 수가 반영 영역 수보다 적으면 생성 전에 차단한다.
- 모델이 영역을 누락하거나 추가하면 결과를 표시하지 않고 생성 결과 형식 오류를 안내한다.
- 정제 과정에서 문장이 비게 되면 결과를 표시하지 않는다.
- 학생 이름은 모델에 전송하지 않고 기존처럼 학생 번호만 사용한다.

## 테스트 기준

1. 네 영역 중 세 영역을 요청하면 모든 학생에게 정확히 세 영역이 선택된다.
2. `매우 잘함` 두 개와 `잘함` 한 개가 있으면 그 세 영역이 하위 단계보다 먼저 선택된다.
3. 같은 단계 후보가 여러 개이면 반 전체에서 영역 조합이 한쪽으로만 쏠리지 않는다.
4. 균형 때문에 하위 성취 단계가 상위 단계보다 먼저 선택되지 않는다.
5. 세 영역 입력에 영역별 평어가 두 개 또는 네 개이면 서버가 거부한다.
6. 선택 영역명과 응답 영역명이 다르면 서버가 거부한다.
7. 정상 응답은 영역별 세 문장을 선택 순서대로 결합한다.
8. 표의 `매우 잘함`이 잘리지 않고 종합의견은 셀 안에서 줄바꿈된다.

## 변경 범위

- `lib/openai.ts`: 구조화 응답 스키마, 검증, 영역별 문장 결합
- `lib/prompt.ts`: 영역당 한 문장 규칙과 JSON 예시
- `types/report.ts`: 필요한 내부 응답 타입 보강
- `app/globals.css`: 영역 열과 종합의견 열 너비 조정
- 관련 테스트: 영역 선택, 프롬프트, OpenAI 응답 검증, 표 레이아웃

사용량 제한, 인증, 교사 비밀번호, 학생 익명화, 파일 분석, 저장 방식은 이번 변경 범위에서 수정하지 않는다.
