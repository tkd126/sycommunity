# 창의적 체험활동 평어와 브라우저 세션 연속성 설계

## 목적

한 학기 전체 시간표 파일에서 창의적 체험활동에 해당하는 날짜와 활동을 먼저 추출하고, 교사가 확인한 각 활동을 한 문장의 창체 평어로 작성한다. 동시에 동아리 활동 기록의 길이를 보완하고, 메뉴 이동이나 새로고침 뒤에도 개인정보를 과도하게 저장하지 않는 범위에서 작업을 이어갈 수 있게 한다.

## 범위

이번 구현은 세 부분으로 나눈다.

1. 동아리 활동 기록을 기존보다 약 2배 긴 한 문장으로 생성하고 브라우저 세션에 보존함.
2. 학기 전체 평가 계획의 추출 내용을 모든 과목에서 공통으로 재사용함.
3. 시간표 파일에서 창체 활동을 추출하고 날짜별 한 문장 평어를 생성하는 새 화면을 추가함.

사용자 계정 기반 장기 저장, 원본 파일 저장, 학생별 창체 평어 생성은 이번 범위에 포함하지 않는다.

## 확정된 업무 규칙

### 실제 학교 파일에서 확인한 구조

제공된 연간시간표 HWP와 창의적 체험활동 종합의견 HWPX를 로컬 메모리에서만 읽어 구조를 확인했다. 원문은 데이터베이스나 애플리케이션 로그에 저장하지 않는다.

- 연간시간표의 시간표 칸에는 `자`, `진`, `동` 같은 한 글자 약어가 사용됨.
- 연간시간표 오른쪽 비고란에는 `3.4(수) 학교폭력예방교육`처럼 날짜와 실제 활동명이 기록됨.
- `자`는 자율활동, `진`은 진로활동으로 해석하고 `동`은 동아리활동이므로 제외해야 함.
- 날짜와 활동명은 시간표 칸 하나만 보거나 비고란만 검색해서 정하지 않고, 같은 주의 시간표 배치와 비고 내용을 함께 해석해야 함.
- 참고 HWPX는 `주`, `날짜`, `시수`, `학습 주제`, `세부 사항 기록` 구조이며, 세부 사항 기록은 활동의 의미와 참여 태도를 구체화한 한 문장으로 작성되어 있음.
- 참고 HWPX의 문체와 길이를 창체 평어 생성 기준으로 사용하지만, 해당 파일 자체를 매번 업로드하도록 요구하거나 결과 파일로 복제하지 않음.
- 최종 결과는 HWPX 파일이 아니라 웹 화면의 `날짜`, `평어` 두 열로만 제공함.

### 창체 추출 대상

- 시간표에서 `창체`, `자율`, `봉사`, `진로`로 표시된 수업을 추출함.
- 실제 시간표의 한 글자 약어 `자`, `봉`, `진`도 각각 자율, 봉사, 진로로 해석함.
- `동`, `동아리`, `동아리활동`으로 표시된 수업은 추출하지 않음.
- 날짜, 구분, 실제 활동명을 함께 추출함.
- 비고란의 날짜와 활동명을 같은 주의 시간표 약어 및 시수와 연결함.
- 같은 날짜에 대상 활동이 두 개 이상이면 각각 별도의 행으로 분리함.
- 날짜는 화면에서 `4/7`처럼 읽기 쉬운 형식으로 표시하되 내부 정렬이 가능하도록 월과 일을 구조화함.

### 창체 평어

- 교사가 확인한 활동 한 건마다 평어 한 문장을 생성함.
- 문장은 긍정적이고 자연스럽게 작성함.
- 명사형 종결어미로 끝냄.
- 외국어, 제품명, 상표명, 불필요한 고유 명사는 일반적인 한국어 표현으로 바꿈.
- 원래 활동에서 벗어난 구체적인 사실을 새로 만들지 않음.
- 참고 HWPX처럼 활동에서 알게 된 점, 실천 의지, 참여 태도 중 활동에 어울리는 내용을 포함해 지나치게 짧지 않은 한 문장으로 작성함.
- 같은 날짜에 활동이 여러 개이면 날짜가 같은 별도 행과 별도 문장으로 표시함.
- 최종 결과 표는 왼쪽 `날짜`, 오른쪽 `평어` 두 열만 표시함.

### 동아리 활동 기록

- 한 학생당 한 문장만 생성함.
- 현재 결과의 약 2배 길이를 목표로 하며 대략 70자에서 110자 범위를 권장함.
- 문장 앞부분에는 실제 활동과 결과물을, 뒷부분에는 꾸준한 참여, 노력, 끈기, 완성 과정 등의 긍정적 태도 표현을 자연스럽게 포함함.
- 제품명과 불필요한 고유 명사는 일반 표현으로 바꿈.
- 명사형 종결어미를 사용함.
- 교사가 입력한 활동과 연결되지 않는 수상, 능력, 성취 사실은 만들지 않음.

## 권장 데이터 흐름

### 1. 전체 평가 계획 공통 사용

교과평어 화면 상단의 평가 계획 안내를 `한 학기 전체 평가 계획을 올려 주세요. 한 번 분석하면 현재 브라우저 탭의 모든 과목에서 공통으로 사용됩니다.`로 변경한다.

평가 계획 파일을 분석하면 다음 정보만 `sessionStorage`에 저장한다.

- 파일명
- 추출된 평가 계획 텍스트
- 분석 시각
- 저장 구조의 버전

원본 HWP, HWPX, PDF 파일 바이트는 브라우저 저장소와 데이터베이스에 저장하지 않는다. 저장된 추출 텍스트는 현재 탭을 닫으면 브라우저가 자동으로 삭제하며, 새로고침이나 상단 메뉴 이동 뒤에는 복원한다. 새 평가 계획을 분석하면 기존 공통 계획을 교체한다.

수행평가지, 평가 기준안, 학생 평가 결과와 학생 이름은 공통 세션 저장소에 넣지 않는다. 이 자료는 과목마다 다시 첨부하며 새로고침하면 제거된다.

### 2. 동아리 작업 세션 보존

동아리 화면의 다음 값은 `sessionStorage`에 저장한다.

- 익명 번호
- 교사가 입력한 동아리 활동 내용
- 생성된 동아리 활동 기록
- 선택 상태와 행 수

Google 계정 이메일, 학생 실명, 원본 파일은 저장하지 않는다. 입력이나 생성 결과가 변경될 때마다 저장하고, 화면을 다시 열거나 새로고침하면 복원한다. 초기화 버튼은 화면 상태와 해당 세션 저장값을 함께 삭제한다.

### 3. 창체 시간표 분석

새 서버 라우트는 시간표 파일을 받아 기존 `extractDocumentText`를 이용해 텍스트를 추출한다. 기본 지원 형식은 HWP와 HWPX이며, 기존 추출기가 지원하는 PDF도 함께 허용한다.

HWP 표는 일반 텍스트 추출 과정에서 열 경계나 날짜 숫자의 일부가 흐트러질 수 있다. 따라서 단순 정규식만으로 확정하지 않고, 서버에서 추출된 전체 시간표 텍스트의 주별 시간표와 비고란을 함께 OpenAI API에 전달해 구조화한다. 응답은 다음 구조의 JSON으로 제한한다.

```json
{
  "activities": [
    {
      "date": "4/7",
      "category": "자율",
      "activity": "다문화 교육",
      "hours": 1,
      "needsReview": false
    }
  ],
  "warnings": []
}
```

서버는 `자`를 자율, `봉`을 봉사, `진`을 진로로 정규화한다. 허용 구분을 `창체`, `자율`, `봉사`, `진로`로 다시 제한하고 `동`, `동아리`, `동아리활동` 행을 제거한다. 날짜와 활동명이 비어 있는 행은 결과에 넣지 않는다. 날짜나 시수 연결이 불확실하면 추측으로 확정하지 않고 `needsReview`를 표시한다. 원본 파일과 추출 텍스트는 데이터베이스나 로그에 저장하지 않는다.

AI 분석은 표 배치를 잘못 해석할 수 있으므로 분석 직후 바로 평어를 만들지 않는다. 교사가 날짜, 구분, 활동명을 확인하고 직접 수정하거나 행을 삭제한 뒤 생성한다.

### 4. 창체 평어 생성

별도 생성 라우트는 교사가 확인한 활동 행만 전달받아 각 행에 대응하는 한 문장 평어를 JSON으로 반환한다. 서버는 로그인과 활성 구독을 확인하고, 기존 월 예산 확인, 요청 빈도 제한, 토큰 제한, 사용량 저장 절차를 동일하게 적용한다.

프론트엔드는 응답의 행 식별자를 기준으로 평어를 정확한 행에 반영한다. 생성된 문장은 textarea에서 교사가 직접 수정할 수 있다.

## 화면 설계

상단 메뉴에 `창의적 체험활동`을 추가하고 왼쪽 사이드바에는 `창체 활동 평어 작성기`를 표시한다.

창체 화면은 다음 순서로 구성한다.

1. 개인정보 및 처리 안내
2. 시간표 HWP, HWPX, PDF 드래그 영역
3. `시간표 분석` 버튼
4. 추출 확인 표
5. `전체 평어 생성`, `결과 복사`, `CSV 다운로드`, `행 추가`, `선택 삭제`, `초기화` 버튼
6. 최종 결과 표

추출 확인 표의 열은 `선택`, `날짜`, `시수`, `구분`, `추출한 활동`, `확인 상태`로 구성하고 모든 값을 수정할 수 있게 한다. 최종 결과 표는 `날짜`, `평어` 두 열만 표시하며 날짜 열을 좁게 두고 평어 열을 넓게 배치한다. 같은 날짜의 여러 활동은 서로 다른 두 행으로 표시한다.

결과 복사는 다음 형식으로 제공한다.

```text
날짜\t평어
4/7\t다문화 교육을 통해 다양한 문화의 특징을 이해하고 서로의 차이를 존중하며 더불어 살아가는 태도의 중요성을 느낌.
```

## 컴포넌트와 서버 경계

- `CreativeActivityGenerator`: 파일 선택, 분석 결과 확인, 생성 결과 수정, 복사와 다운로드를 담당함.
- `lib/creative-activity.ts`: 허용 구분, 날짜 정규화, 중복 제거, 금지 표현 후처리를 담당함.
- `lib/session-storage.ts`: 버전이 있는 안전한 세션 데이터 읽기와 쓰기를 담당함.
- `app/api/creative-activities/parse/route.ts`: 파일 검증, 텍스트 추출, 구조화 분석을 담당함.
- `app/api/creative-activities/generate/route.ts`: 확인된 활동을 한 문장 평어로 생성함.
- 기존 `lib/sanitize.ts`, `lib/usage.ts`, `lib/rate-limit.ts`, 인증 도우미를 재사용함.

서버 라우트는 브라우저가 보낸 생성 결과나 권한 필드를 신뢰하지 않는다. 파일 크기, 허용 확장자, 입력 텍스트 길이, 행 수, 각 필드 길이를 서버에서 다시 검증한다.

## 오류 처리

- 지원하지 않는 파일: HWP, HWPX, PDF만 가능하다고 안내함.
- 파일이 너무 큼: 제한 용량과 함께 다시 안내함.
- 대상 활동을 찾지 못함: `창체, 자율, 봉사, 진로 또는 자, 봉, 진 표기를 찾지 못했습니다.`라고 안내하고 수동 행 추가를 허용함.
- 날짜, 시수 또는 활동명이 불명확함: 해당 행에 확인 필요 표시를 하고 생성 전 수정하도록 함.
- OpenAI 응답이 JSON이 아님: 결과를 반영하지 않고 재시도 가능한 오류를 표시함.
- 월 예산 초과 또는 비활성 계정: 기존 공통 오류 형식을 사용함.
- 세션 저장 데이터가 손상됨: 오류를 노출하지 않고 해당 기능의 세션 데이터만 초기화함.

## 개인정보와 보안

- 시간표 원본, 추출된 전체 텍스트, 창체 생성 결과를 데이터베이스에 저장하지 않음.
- 평가 계획 원본, 수행평가지, 평가 기준안, 학생 성적 파일을 브라우저 영구 저장소에 저장하지 않음.
- `localStorage`를 사용하지 않고 현재 탭에 한정된 `sessionStorage`만 사용함.
- 세션 저장 데이터에는 학생 실명과 Google 이메일을 넣지 않음.
- OpenAI API 키는 기존과 동일하게 서버에서만 사용함.
- 서버 로그에 파일 원문과 생성 입력을 남기지 않음.

## 테스트 기준

### 동아리

- 생성 프롬프트가 한 문장과 목표 길이를 요구함.
- 제품명 대체와 명사형 종결 규칙이 유지됨.
- 입력과 생성 결과가 새로고침 뒤 복원됨.
- 초기화하면 세션 저장값도 삭제됨.

### 평가 계획

- 분석된 공통 평가 계획이 과목을 바꾸거나 새로고침한 뒤 복원됨.
- 새 계획이 기존 계획을 교체함.
- 원본 파일과 학생 평가 자료는 세션 저장소에 기록되지 않음.

### 창체

- 창체, 자율, 봉사, 진로를 허용함.
- 자, 봉, 진 약어를 올바른 구분으로 정규화함.
- 동, 동아리, 동아리활동을 제외함.
- 주별 시간표의 약어와 비고란의 날짜 및 활동명을 함께 연결함.
- 같은 날짜의 두 활동을 두 행으로 유지함.
- 날짜 또는 시수 연결이 불확실한 행을 확인 필요로 표시함.
- 날짜 정렬과 날짜 형식 정규화가 동작함.
- 추출 결과를 수정한 값이 생성 요청에 사용됨.
- 평어가 한 문장, 명사형 종결, 한국어 중심 규칙을 따름.
- 비활성 사용자, 잘못된 파일, 예산 초과, 잘못된 JSON 응답을 안전하게 처리함.
- 원본 파일과 전체 추출 텍스트를 데이터베이스에 저장하지 않음.

## 완료 기준

- 동아리 기록이 기존보다 약 2배 긴 한 문장으로 생성됨.
- 동아리 작업과 공통 평가 계획 추출 내용이 새로고침 뒤 복원되고 탭 종료 시 삭제됨.
- 과목별 민감 자료는 공통 저장되지 않음.
- 시간표 파일에서 창체, 자율, 봉사, 진로 활동이 날짜와 함께 추출됨.
- 동아리 활동은 창체 결과에서 제외됨.
- 같은 날짜의 복수 활동이 별도 행과 별도 평어로 생성됨.
- 최종 웹 표에 날짜와 평어 두 열만 표시되며 바로 복사할 수 있음.
