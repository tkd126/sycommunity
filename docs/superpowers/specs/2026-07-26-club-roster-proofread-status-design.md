# 동아리 학생 수 설정과 맞춤법 상태 표시 설계

## 목적

동아리 활동 기록 작성기에 1~40명 학생 수를 지정하는 입력과 목록 생성 버튼을 추가하고, 맞춤법 검사 후 각 학생 결과가 수정되었는지 여부를 행별로 명확하게 표시한다.

## 학생 수 동작

- 기본 학생 수는 현재 행 수와 일치한다.
- 사용자는 1~40 사이의 정수를 입력하고 `학생 목록 만들기`를 누른다.
- 인원을 늘리면 기존 행을 보존하고 뒤에 익명 학생 행을 추가한다.
- 인원을 줄이면 앞번호 행을 보존하고 뒤쪽 행을 제거한다.
- 잘못된 값은 적용하지 않고 안내 문구를 표시한다.
- 행 추가·삭제·세션 복원 후 학생 수 입력값도 현재 행 수와 동기화한다.

## 맞춤법 검사 상태

- 행 상태는 `unchecked`, `clean`, `corrected` 세 가지로 관리한다.
- 검사 응답이 원문과 같으면 `문제 없음`, 달라졌으면 `수정됨` 배지를 기록 입력칸 아래에 표시한다.
- 사용자가 기록을 직접 수정하거나 새 활동 기록을 생성하면 해당 행 상태는 `unchecked`로 돌아간다.
- 검사 전 결과로 되돌리면 검사 상태도 초기화한다.
- 상태는 현재 탭의 sessionStorage 작업 상태에 포함할 수 있으나 학생 실명이나 원문 외 추가 개인정보는 생성하지 않는다.

## 검증

- 지정 인원으로 확장·축소할 때 기존 행 값 보존
- 범위 오류 처리
- 맞춤법 검사 결과별 배지 표시
- 직접 수정·새 생성·복원 시 상태 초기화
