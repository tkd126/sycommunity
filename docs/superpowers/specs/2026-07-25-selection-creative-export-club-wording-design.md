# 선택 제어·창체 내보내기·동아리 문장 개선 설계

## 목표

창체와 동아리 표에서 전체 선택과 전체 선택 해제를 명확히 제공하고, 서로 겹치는 활동은 더 구체적인 내용을 생성 근거로 사용한다. 창체 결과는 사용자가 수정한 평어를 포함해 한컴오피스에서 안정적으로 열리는 파일로 내려받고, 동아리 문장은 시간 순서에 맞는 간결한 한 문장으로 생성한다.

## 설계

### 선택 상태

- 창체와 동아리 도구 모음에 `전체 선택`과 `전체 선택 해제` 버튼을 둔다.
- 두 버튼은 현재 행의 `selected` 값만 일괄 변경하며 입력 내용과 생성 결과는 보존한다.
- 각 표의 첫 열 제목은 그대로 `선택`으로 유지해 행별 선택도 가능하게 한다.

### 유사 활동 구체화

- 같은 입력 칸에 쉼표 등으로 나열된 활동 중 핵심 단어가 겹치는 항목은 중복 활동으로 본다.
- 중복 활동에서는 더 긴 수식어를 가진 구체적인 항목을 생성 근거로 선택한다.
- 서로 다른 활동은 합치거나 삭제하지 않는다.
- 화면의 교사 입력 원문은 보존하고 API에 전달하는 활동명만 구체화한다.

### 한글 파일 내보내기

- 현재 OWPML 생성 결과에서 MIME 값만 바꾸는 방식은 사용하지 않는다.
- 제공된 정상 HWPX 문서의 패키지 규격을 기준으로 개인정보와 기존 본문이 없는 호환 템플릿을 사용한다.
- 화면에서 현재 보이는 날짜, 시수, 활동, 사용자가 수정한 평어를 다운로드 시점에 표 행으로 삽입한다.
- 브라우저 다운로드 MIME과 파일 확장자도 HWPX에 맞춘다.
- 한컴 버전별 호환 문제를 대비해 동일 내용을 DOCX로 내려받는 보조 버튼을 제공한다.

### 동아리 문장

- 한 문장에 핵심 행동을 최대 두 단계로 구성한다.
- `전시함`, `발표함`, `완성함` 같은 결과 행동은 항상 마지막에 둔다.
- 입력에 없는 성실성·꾸준함을 자동으로 덧붙이지 않는다.
- 입력에 참여 태도가 명시된 경우에만 자연스럽게 한 번 반영한다.

## 오류 처리

- 내보낼 평어가 없으면 다운로드하지 않고 안내한다.
- 템플릿을 읽거나 문서를 조립하지 못하면 기존과 동일한 오류 알림을 표시한다.
- 유사 활동 판정이 불확실하면 원문 전체를 유지한다.

## 검증

- 컴포넌트 테스트로 두 표의 전체 선택과 전체 선택 해제를 검증한다.
- 창체 생성 요청 본문에서 구체적인 활동만 사용되는지 검증한다.
- HWPX ZIP의 필수 엔트리, MIME, 본문 XML과 수정 평어를 검증한다.
- DOCX 파일 시그니처와 수정 평어를 검증한다.
- 동아리 문장의 시간 순서와 반복 접속어 부재를 검증한다.
