# 교과 평어 성능·세션 복원 설계

## 목표

교과 평어 생성과 새로고침 체감 시간을 줄이고, 브라우저 탭이 열려 있는 동안 익명화된 작업 상태를 복원하며, 일반 데스크톱 화면에서 결과표의 가로 스크롤을 제거한다.

## 데이터 경계

- 저장 허용: 선택 과목, 반영 영역 수, 익명화된 분석 결과, 학생 번호, 영역 단계, 선택 영역, 생성 평어, 예시문, 추가 지시사항.
- 저장 금지: 교사 접근 비밀번호, 원본 파일 객체, 원본 학생 이름, 원문 평가결과 파일.
- 저장소는 `sessionStorage`를 사용한다. 새로고침과 메뉴 이동에는 유지되며 마지막 탭을 닫으면 브라우저가 제거한다.

## 성능 설계

- 평어 생성은 비용과 분당 요청 제한을 증가시키는 학생별 병렬 호출로 분할하지 않는다.
- 서버에 보내는 평가 계획과 수행평가지 텍스트를 학생별 근거 작성에 필요한 상한으로 축약하고, 출력 토큰 상한은 요청 학생 수에 따라 계산한다.
- 초기 화면에서 저장본 목록 API를 자동 호출하지 않고 사용자가 저장본 영역을 열거나 새로고침할 때만 호출한다.
- 세션 복원은 초기 상태 함수에서 동기적으로 수행해 첫 렌더 후 상태가 뒤늦게 바뀌는 현상을 막는다.

## 표 설계

- 선택·번호·이름·과목·영역 열은 내용이 보이는 최소 너비로 유지한다.
- 선택 영역 열을 축소하고 종합의견 열은 남은 폭을 사용한다.
- 교과 결과표는 `width: 100%`와 고정 레이아웃을 사용하고, 셀 내부 문장은 자연스럽게 줄바꿈한다.

## 오류 처리와 테스트

- 손상되거나 이전 버전인 세션 값은 폐기하고 기본 상태로 시작한다.
- 세션 저장 용량 초과는 화면 기능을 중단시키지 않는다.
- 테스트는 새로고침 복원, 민감정보 비저장, 출력 토큰 동적 상한, 지연 저장본 호출, 표 너비 규칙을 검증한다.
