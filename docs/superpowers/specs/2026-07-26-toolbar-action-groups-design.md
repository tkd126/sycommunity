# 작업 버튼 그룹 재구성 설계

## 목표

교과평어, 동아리활동, 창체활동 표에서 선택과 생성 버튼이 섞여 보이는 문제를 해결한다. 사용 흐름을 `선택 관리`, `생성`, `결과 관리` 순서로 통일하고 가장 중요한 생성 동작을 시각적으로 분리한다.

## 화면 구조

- 제목과 전체 인원 정보는 기존 위치를 유지한다.
- 작업 버튼 영역은 세 개의 의미 있는 그룹으로 나눈다.
- 첫 그룹은 `선택 관리`이며 `전체 선택`, `전체 선택 해제`, `선택 삭제` 순서로 둔다.
- 두 번째 그룹은 `생성`이며 연한 파란 배경과 테두리로 강조한다. 기본 생성 버튼은 파란색 주 버튼으로 표시하고 선택 생성과 전체 생성은 보조 버튼으로 둔다.
- 세 번째 그룹은 `결과 관리`이며 복사, 다운로드, 행 추가, 초기화를 배치한다.
- 창체의 확인 버튼은 선택 관리와 생성 사이에 `검토` 그룹으로 분리한다.
- 화면 폭이 좁아지면 그룹 단위로 다음 줄에 배치하되 그룹 내부 순서는 유지한다.

## 적용 화면

- `ReportGenerator`: 교과평어 학생 결과 표
- `ClubActivityGenerator`: 동아리 활동 기록 표
- `CreativeActivityGenerator`: 창체 추출 활동 검토 표

## 접근성 및 검증

- 각 그룹에 `aria-label`을 부여해 보조 기술에서도 역할을 구분한다.
- DOM 순서 테스트로 선택 관리가 생성보다 먼저 나오는지 확인한다.
- 세 화면 모두 그룹 이름과 버튼 순서를 회귀 테스트한다.
