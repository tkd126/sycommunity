# 게임 글꼴

- Jua: 이름표, 선택지, 메뉴. https://github.com/google/fonts/tree/main/ofl/jua
- Gowun Dodum: 대사와 본문. https://github.com/google/fonts/tree/main/ofl/gowundodum

원본 TTF를 게임에 포함하여 오프라인으로도 사용합니다. 각 OFL 라이선스 파일을 함께 배포하세요.

UI 방향: 기존 미스터리 미연시의 남색/금색을 보존하는 부분 개편.
DESIGN_VARIANCE 4 / MOTION_INTENSITY 3 / VISUAL_DENSITY 4.
마케팅 페이지용 스킬에서 글꼴, 대비, 간격, 포커스 규칙만 적용합니다.
스토리, 배경, 분기 구조는 변경하지 않습니다.
