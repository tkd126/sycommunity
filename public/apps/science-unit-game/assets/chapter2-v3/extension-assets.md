# 2편 후반 이미지

내장 imagegen 도구 사용. 원본 출력은 Codex generated_images에 보존하고 아래 PNG를 프로젝트로 복사했다.

- binder-clip.png: 투명 배경, 검은 스프링 강판 몸체와 두 은색 철제 손잡이가 있는 문구용 더블클립. 3/4 시점, 금속 하이라이트, TV 애니메이션풍. 기존 SVG 도형 대체. 알파 채널 확인.
- archive.png: 1999년 학교 자료실. 겨울빛, 목재 책상, 왼쪽 촬영 일지·중앙 봉투·오른쪽 사진, 벽 약도와 서가. 인물·글자 없음. 조사할 사물은 분리 배치.
- photo-comparison.png: 같은 겨울 운동장 사진 세 장. 왼쪽 선명한 시야/오른쪽 깃발, 가운데 낮은 안개/오른쪽 깃발, 오른쪽 낮은 안개/왼쪽 깃발. 글자 없음. UI에서 번호와 관측 기록 표시.
- archive-evidence.png: 빨간 수선 표시가 있는 검은 카세트, 빨간 끈 끝이 풀린 남색 스프링 수첩 위. 사진 가장자리 일부 소매와 손, 얼굴 없음. 겨울빛 카툰 삽화.

위 항목은 실제 생성에 사용한 프롬프트의 한국어 요약이다. 후반은 하나의 정체를 확정하지 않는다. 정답은 일지와 약도 조사 후에만 제출 가능하며 마지막 단서 대화를 모두 읽어야 결말로 이동한다.
